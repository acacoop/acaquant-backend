# web/components/dual-range

**Archivo:** `src/components/dual-range.tsx`

## Qué hace
Control de UI de doble slider (rango lo/hi) sobre un mínimo y máximo dados, con la franja seleccionada resaltada. Sirve para filtrar por rango (ej. días al vencimiento) en las vistas analíticas.

Conecta con: componente de presentación puro (props lo/hi/setLo/setHi); lo usan `web.cmp.descomposicion-tab` y `flujo-vs-aum-view`. No pega a la API.
