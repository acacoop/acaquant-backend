# web/components/dolar-mep-board

**Archivo:** `src/components/dolar-mep-board.tsx`

## Qué hace
Layout reutilizable del módulo Dólar MEP: split horizontal con el gráfico de la serie MEP por minuto a la izquierda (50%) y una tabla específica de cada vista a la derecha (children). Lo comparten las vistas de compra y de venta/trading.

Conecta con: monta `web.cmp.dolar-mep-timesales-chart`; lo usan `web.cmp.dolar-mep-compra-view` y `web.cmp.dolar-mep-venta-view`.
