Módulo de tipos y helpers compartidos entre las sub-vistas de Dólar MEP (compra y trading): define los shapes Cotizacion, OperativaMep, PataOrden, SaldoCuenta y utilidades de formato (fmtArs, fmtTime), colores de estado y celdas de tabla reutilizables.

Conecta con: lo importan `web.cmp.dolar-mep-shell`, `dolar-mep-compra-view`, `dolar-mep-venta-view` y `dolar-mep-board`. No pega a la API; es pura capa de presentación.
